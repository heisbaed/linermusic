# Cine music artwork

Place your image pack in this folder. The current app uses temporary vector artwork.

Useful source assets:

- A square app icon (ideally 1024 x 1024, with the symbol comfortably inside the center).
- A separate transparent foreground symbol for the Android adaptive icon.
- Splash artwork or a transparent logo, plus the intended background color.
- Any empty-library, offline, or player artwork you want in the interface.

Keep the full-resolution originals here. Android launch icons and splash resources
will be derived from these source files after they arrive.
